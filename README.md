# QUN Consulting

Responsive cybersecurity consulting website.

## Publish with GitHub Pages
Go to **Settings → Pages → Build and deployment**. Choose **Deploy from a branch**, select **main** and **/(root)**, then save.

Expected URL: https://smimran-alt.github.io/QUN-Consulting/

## Before collecting inquiries
Configure a verified business email or form backend and a suitable privacy notice. The current form only prepares/copies inquiry details; it does not submit data to a server.

Update service, company, contact and legal claims prior to commercial launch.
